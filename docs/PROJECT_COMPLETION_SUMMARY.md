## 🔄 重要技术迁移

### Doubao-Seed API 迁移
从 Chat Completions API 迁移到 Files API + Responses API：

**迁移前**:
```javascript
POST /chat/completions
Body: { messages: [...] }
```

**迁移后**:
```javascript
// 1. 上传文件
POST /files
FormData: { file: videoFile }

// 2. 创建分析任务
POST /responses
Body: { input: [...] }
```

**迁移收益**:
- 更稳定的文件处理
- 更好的错误处理
- 支持更大的视频文件
- 更清晰的 API 结构

### 图像生成统一
将所有图像生成功能统一到 Gemini API：
- 角色转身图生成
- 场景参考图生成
- 统一的错误处理
- 一致的 API 调用模式

3. **分块上传** - 支持大文件上传
4. **WebSocket** - 实时进度推送
5. **统一封装** - 服务层统一错误处理
