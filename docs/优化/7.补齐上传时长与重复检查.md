# 补全提示词 7：补齐上传阶段的时长上限与重复上传检查

你是资深全栈工程师。

任务：在不改变现有上传接口语义的前提下，补齐上传阶段缺失的校验项：视频时长上限和重复上传检查。

修改范围：
- `frontend/src/hooks/useVideoUpload.js`
- `backend/services/videoService.js`
- `backend/services/ffmpegService.js`
- 如有必要，可补充 `backend/config/constants.js`

要求：
1. 前端保留现有格式和大小校验。
2. 新增时长上限校验：
   - 优先使用后端元数据校验；
   - 如果前端可快速拿到 `metadata`，可做预检查，但以后端为准。
3. 新增重复上传检查：
   - 在单用户当前项目场景下，至少基于 `filename + file_size` 做一次轻量重复判断；
   - 不要求复杂去重，不引入哈希大改造。
4. 不改变 `POST /videos/upload` 的路径和基本返回结构。
5. 校验失败时给出清晰错误信息。
6. 增加最小测试提示，覆盖超长视频和重复上传。

预期结果：
- 上传阶段与项目文档要求一致，不再只校验格式和大小。
