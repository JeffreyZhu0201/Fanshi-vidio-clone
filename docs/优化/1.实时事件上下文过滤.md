# 补全提示词 1：修复 WebSocket 串线，按当前上下文过滤事件

你是资深 React 工程师。

任务：在不改变现有 API 和 UI 语义的前提下，修复前端实时事件串线问题，只让当前视频/当前任务的事件更新页面状态。

修改范围：
- `frontend/src/hooks/useAnalysis.js`
- `frontend/src/hooks/useSegments.js`
- `frontend/src/hooks/useGeneration.js`
- `frontend/src/store/generationStore.js`
- 如有必要，可小幅补充 `frontend/src/store/videoStore.js`

要求：
1. `analysis:progress` 只在 `payload.video_id` 等于当前 `currentVideo.id` 时更新 `analysisStore`。
2. `split:progress` 只在当前激活的 `split taskId` 一致时更新 `splitProgress`；开始新的 split 任务时要覆盖旧 `taskId`。
3. `merge:progress` 只在当前激活的 `merge taskId` 一致时更新 `mergeProgress`；开始新的 merge 任务时要覆盖旧 `taskId`。
4. `generation:progress` 只更新当前页面已有 `segment.id` 对应的片段，不要让其他视频片段的任务污染当前 store。
5. 不要改现有接口路径、请求参数、返回结构。
6. 保持现有 UI 行为不变，只修正状态归属。
7. 增加最小必要注释说明过滤规则。

预期结果：
- 多视频、多标签页、旧任务未结束时，当前页面不会被其他任务状态覆盖。
