# 补全提示词 6：切换新视频时立即清空旧上下文，避免旧数据残留

你是资深 React 工程师。

任务：修复上传新视频后旧视频分析结果、片段列表、拼接进度仍残留的问题，不改变现有交互流程。

修改范围：
- `frontend/src/hooks/useVideoUpload.js`
- `frontend/src/hooks/useAnalysis.js`
- `frontend/src/hooks/useSegments.js`
- `frontend/src/store/analysisStore.js`
- `frontend/src/store/generationStore.js`

要求：
1. 当 `currentVideo` 被新的上传结果替换时，立即清空旧视频上下文：
   - `analysis`
   - `segments`
   - `splitProgress`
   - `mergeProgress`
   - `tasks`
2. 清空要发生在新视频的 hydrate 请求之前，避免页面先显示旧视频数据再切换。
3. 如果新视频已有分析或已有片段，再按现有 GET 接口重新填充。
4. 不要影响“重新分析”“重新分割”的已有行为。
5. 不要修改 `MainPage` 布局和组件职责。

预期结果：
- 切换到新视频时，页面不会短暂展示旧视频的分析结果和片段卡片。
