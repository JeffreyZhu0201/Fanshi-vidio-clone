# 补全提示词 4：统一片段展示结果与拼接结果来源

你是资深 Node.js + React 工程师。

任务：修复“片段卡片展示的最新结果”和“后端拼接实际使用的结果”不一致的问题，不改变现有生成/拼接接口语义。

修改范围：
- `backend/services/segmentService.js`
- `frontend/src/hooks/useSegments.js`
- `frontend/src/hooks/useGeneration.js`

要求：
1. 明确统一规则：
   - 片段列表展示给前端的 `latest_generation_task`，必须和后端 merge 选择片段时采用的结果来源一致。
2. 当前 merge 使用“最近一次 `completed` 的生成任务”，因此 segment 列表返回给前端时也应基于相同口径。
3. 如果某个片段最近一次任务失败，但历史上有成功结果：
   - 前端仍应能显示上一次成功生成的视频；
   - 同时要能显示最近失败任务状态，不要丢失失败信息。
4. 不改变现有 `/segments/:videoId` 和 `/generation/:taskId` 路径。
5. 可以在返回结构中补充最小必要字段，但不要破坏现有字段。
6. 前端卡片要优先展示可用的生成结果，同时保留失败态提示。

预期结果：
- 用户在片段卡片里看到的“可预览结果”，和最终 merge 实际使用的素材来源一致。
