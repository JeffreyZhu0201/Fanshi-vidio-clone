# 补全提示词 5：补齐 split/generate/merge/optimize 的异常处理与轮询取消

你是资深 React 工程师。

任务：在不改变现有业务语义的前提下，补齐前端异步流程的失败态、重试提示和轮询取消，避免 Promise 未处理和状态卡死。

修改范围：
- `frontend/src/hooks/useSegments.js`
- `frontend/src/hooks/useGeneration.js`
- `frontend/src/hooks/useAnalysis.js`

要求：
1. `splitFromAnalysis`、`optimizeSegmentPrompt`、`generateSegmentVideo`、`startMerge` 都要补 `try/catch`。
2. 网络错误、超时、404、500 都要转成明确的用户可见错误信息，写入对应 store。
3. 轮询逻辑要支持取消：
   - 组件卸载时停止轮询；
   - `currentVideo` 切换时停止旧视频轮询；
   - 新任务开始时终止旧任务轮询。
4. 不要破坏现有按钮行为和接口调用顺序。
5. 生成和拼接按钮在异常结束后要能恢复可点击状态。
6. 给每个流程补一个最小失败态测试提示，至少覆盖：
   - 轮询中途 500
   - 请求超时
   - 组件卸载/切换视频时取消轮询

预期结果：
- 异步任务不再因为网络波动或页面切换而把 UI 卡在“处理中”。
