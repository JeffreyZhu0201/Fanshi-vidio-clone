# 补全提示词 8：对齐健康状态与 split 错误字段契约

你是资深前后端联调工程师。

任务：做一次小范围契约对齐，不改变现有功能语义，只修正状态字段消费不完整的问题。

修改范围：
- `frontend/src/hooks/useAppHealth.js`
- `frontend/src/store/appStore.js`
- `frontend/src/hooks/useSegments.js`

要求：
1. `useAppHealth` 要消费 `/api/health` 返回的 `database.connected` 或 `status=degraded`：
   - 后端服务在线但数据库不可用时，不要显示成完全健康；
   - 保持现有 UI 组件可用，尽量只补状态映射。
2. `split:progress` 的错误字段要兼容后端当前发出的 `error_message`。
3. 不要修改后端接口结构。
4. 不改变现有页面布局和按钮行为。

预期结果：
- 健康状态能真实反映“服务在线但数据库降级”的情况；
- split 任务失败时，错误信息字段不再漏接。
