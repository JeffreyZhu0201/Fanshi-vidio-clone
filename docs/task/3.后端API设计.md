## 后端 API 设计提示词

```
你是一个资深 Node.js 后端工程师。

任务：为 Fanshi-vidio-clone 项目设计并实现后端 API。

要求：

1. 创建以下 API 端点：

   【视频管理】
   - POST /api/videos/upload
     请求: multipart/form-data (video file)
     响应: { id, filename, duration, status }
     
   - GET /api/videos/:id
     响应: { id, filename, duration, status, project_id }
     
   - DELETE /api/videos/:id
     响应: { success: true }

   【分析服务】
   - POST /api/analysis/analyze
     请求: { video_id }
     响应: { id, video_id, status, plot, characters, backgrounds, time_anchors }
     
   - GET /api/analysis/:video_id
     响应: { id, video_id, plot, characters, backgrounds, time_anchors }
     
   - POST /api/analysis/optimize-prompt
     请求: { prompt, characters }
     响应: { optimized_prompt, highlighted_prompt }

   【视频处理】
   - POST /api/segments/split
     请求: { video_id, time_anchors }
     响应: { task_id, status, progress }
     
   - GET /api/segments/:video_id
     响应: [{ id, segment_index, start_time, end_time, file_path, analysis }]
     
   - POST /api/generation/generate
     请求: { segment_id, prompt }
     响应: { task_id, status }

   【视频合成】
   - POST /api/merge/start
     请求: { video_id }
     响应: { task_id, status }
     
   - GET /api/merge/:task_id/progress
     响应: { progress, status, message }
     
   - GET /api/merge/:task_id/download
     响应: 文件流

2. 实现文件上传处理：
   - 使用 multer 中间件
   - 文件大小限制 500MB
   - 文件类型验证 (mp4, mov, avi)
   - 存储到 backend/uploads/videos/
   - 返回文件元数据

3. 实现错误处理：
   - 统一的错误响应格式
   - HTTP 状态码正确
   - 错误日志记录
   - 用户友好的错误消息

4. 实现输入验证：
   - 使用 joi 验证请求数据
   - 验证规则清晰
   - 返回详细的验证错误

5. 实现异步任务处理：
   - 视频分析异步执行
   - 视频分割异步执行
   - 视频生成异步执行
   - 使用 Bull 队列或简单的 Promise

6. 编写 Swagger 文档：
   - 安装 swagger-ui-express
   - 定义所有端点的 OpenAPI schema
   - 在 /api-docs 路由提供文档

代码规范：
- 使用 async/await
- 错误处理完善
- 日志记录详细
- 代码注释清晰
- 遵循 MVC 架构
```

## 文件上传服务提示词

```
你是一个资深 Node.js 文件处理专家。

任务：为 Fanshi-vidio-clone 项目实现文件上传服务。

要求：

1. 创建 backend/middleware/upload.js：
   - 配置 multer
   - 设置文件大小限制 (500MB)
   - 设置文件类型过滤 (mp4, mov, avi)
   - 设置存储路径 (backend/uploads/videos/)
   - 自定义文件名 (时间戳 + 随机数)

2. 创建 backend/services/videoService.js：
   - 上传文件保存
   - 获取视频元数据 (时长、分辨率等)
   - 文件验证
   - 数据库记录

3. 创建 backend/controllers/videoController.js：
   - uploadVideo() - 处理上传请求
   - getVideo() - 获取视频信息
   - deleteVideo() - 删除视频

4. 创建 backend/routes/video.js：
   - POST /api/videos/upload
   - GET /api/videos/:id
   - DELETE /api/videos/:id

5. 错误处理：
   - 文件过大
   - 文件类型不支持
   - 磁盘空间不足
   - 数据库错误

代码规范：
- 使用 multer 中间件
- 异步文件操作
- 完善的错误处理
- 日志记录
```

## Gemini 集成提示词

```
你是一个资深 AI API 集成专家。

任务：为 Fanshi-vidio-clone 项目集成 Gemini API。

要求：

1. 创建 backend/services/geminiService.js：
   - 初始化 Gemini 客户端
   - 实现 analyzeVideo() 方法
   - 实现 optimizePrompt() 方法
   - 错误处理和重试机制

2. analyzeVideo() 方法：
   - 输入: 视频文件路径
   - 调用 Gemini API 分析视频
   - 提取: 剧情、角色、背景、时间锚点
   - 返回: 结构化的分析结果

3. optimizePrompt() 方法：
   - 输入: 原始提示词、角色列表
   - 调用 Gemini API 优化提示词
   - 返回: 优化后的提示词

4. 错误处理：
   - API 调用失败重试
   - 超时处理
   - 速率限制处理
   - 详细的错误日志

5. 环境变量：
   - GEMINI_API_KEY 配置
   - API 端点配置
   - 超时时间配置

代码规范：
- 使用官方 SDK
- 异步操作
- 完善的错误处理
- 日志记录详细
```

## FFmpeg 集成提示词

```
你是一个资深 FFmpeg 集成专家。

任务：为 Fanshi-vidio-clone 项目集成 FFmpeg。

要求：

1. 创建 backend/services/ffmpegService.js：
   - 初始化 FFmpeg
   - 实现 splitVideo() 方法
   - 实现 mergeVideos() 方法
   - 进度跟踪

2. splitVideo() 方法：
   - 输入: 视频路径、时间锚点数组
   - 使用 FFmpeg 分割视频
   - 输出: 片段文件列表
   - 返回: 片段信息数组

3. mergeVideos() 方法：
   - 输入: 片段文件列表
   - 使用 FFmpeg 合并视频
   - 输出: 最终视频文件
   - 返回: 输出文件路径

4. 进度跟踪：
   - 监听 FFmpeg 进度
   - 计算完成百分比
   - 实时更新数据库

5. 错误处理：
   - FFmpeg 命令失败
   - 文件不存在
   - 磁盘空间不足
   - 详细的错误日志

6. 性能优化：
   - 使用硬件加速 (如可用)
   - 合理的编码参数
   - 并行处理多个片段

代码规范：
- 使用 fluent-ffmpeg 库
- 异步操作
- 完善的错误处理
- 进度回调
```
