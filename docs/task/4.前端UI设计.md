## 前端 UI 设计提示词

```
你是一个资深 React UI/UX 工程师。

任务：为 Fanshi-vidio-clone 项目设计并实现前端 UI。

要求：

1. 创建单页面布局 (MainPage.jsx)：
   - 顶部导航栏 (Logo、项目名、用户菜单)
   - 3 列主工作区：
     * 左侧栏 (上传区 + 拼接区)
     * 中间区 (分析展示)
     * 右侧栏 (片段卡片列表)
   - 响应式设计 (Tailwind CSS)

2. 实现 6 个核心组件：

   a) UploadArea.jsx - 视频上传区
      - 拖拽上传
      - 文件选择
      - 进度条
      - 文件验证提示
      - 上传状态显示

   b) AnalysisDisplay.jsx - 分析结果展示
      - 剧情内容展示
      - 角色形象卡片
      - 背景描述
      - 时间轴展示
      - 加载状态

   c) SegmentCard.jsx - 片段卡片
      - 视频预览缩略图
      - 片段时间范围
      - 待生成占位框
      - 提示词编辑框
      - 优化按钮
      - 生成按钮
      - 角色标签 (@符号蓝色)

   d) PromptEditor.jsx - 提示词编辑器
      - 文本编辑区
      - 角色标签高亮
      - 优化按钮
      - 字数统计
      - 撤销/重做

   e) VideoMerge.jsx - 视频拼接区
      - 拼接按钮
      - 进度条 (实时更新)
      - 状态文本
      - 下载按钮
      - 完成提示

   f) ProgressBar.jsx - 进度条组件
      - 百分比显示
      - 动画效果
      - 状态颜色变化
      - 时间估算

3. 样式设计：
   - 主色: #6366F1 (靛蓝)
   - 辅色: #EC4899 (粉红)
   - 背景: #F8FAFC (浅灰)
   - 文字: #1E293B (深灰)
   - 使用 Tailwind CSS 实现
   - 支持深色模式 (可选)

4. 交互设计：
   - 拖拽上传视频
   - 实时进度反馈
   - 卡片式片段展示
   - 内联编辑提示词
   - 角色标签自动高亮
   - 平滑的过渡动画

5. 响应式设计：
   - 桌面版 (1920px+)
   - 平板版 (768px-1920px)
   - 移动版 (< 768px)

代码规范：
- 使用函数组件 + Hooks
- PropTypes 类型检查
- 组件高度可复用
- 清晰的文件结构
- 注释完善
```

## 状态管理提示词

```
你是一个资深 React 状态��理专家。

任务：为 Fanshi-vidio-clone 项目设计状态管理。

要求：

1. 使用 Zustand 创建状态 store：

   a) frontend/src/store/videoStore.js
      - 状态: currentVideo, videos, uploadProgress
      - 方法: setCurrentVideo, addVideo, updateProgress, clearVideos

   b) frontend/src/store/analysisStore.js
      - 状态: analysis, loading, error
      - 方法: setAnalysis, setLoading, setError, clearAnalysis

   c) frontend/src/store/generationStore.js
      - 状态: segments, tasks, mergeProgress
      - 方法: setSegments, addTask, updateTask, setMergeProgress

2. 每个 store 包含：
   - 初始状态
   - 状态更新方法
   - 异步操作处理
   - 错误处理

3. 创建自定义 Hooks：
   - useVideoUpload() - 视频上传逻辑
   - useAnalysis() - 分析逻辑
   - useGeneration() - 生成逻辑
   - useSegments() - 片段管理逻辑

4. 状态流：
   - 上传视频 → 更新 videoStore
   - 分析视频 → 更新 analysisStore
   - 分割视频 → 更新 generationStore
   - 生成片段 → 更新 generationStore
   - 拼接视频 → 更新 mergeProgress

代码规范：
- 使用 Zustand 简洁语法
- 状态不可变更新
- 异步操作使用 async/await
- 错误处理完善
```

## API 集成提示词

```
你是一个资深 React API 集成专家。

任务：为 Fanshi-vidio-clone 项目实现 API 集成。

要求：

1. 创建 frontend/src/services/api.js：
   - 创建 axios 实例
   - 配置基础 URL (从 .env 读取)
   - 配置请求/响应拦截器
   - 错误处理

2. 创建 API 调用方法：
   - uploadVideo(file) - 上传视频
   - analyzeVideo(videoId) - 分析视频
   - getAnalysis(videoId) - 获取分析结果
   - optimizePrompt(prompt, characters) - 优化提示词
   - splitVideo(videoId, timeAnchors) - 分割视频
   - getSegments(videoId) - 获取片段列表
   - generateSegment(segmentId, prompt) - 生成片段
   - mergeVideos(videoId) - 拼接视频
   - getMergeProgress(taskId) - 获取拼接进度
   - downloadVideo(taskId) - 下载视频

3. 错误处理：
   - 网络错误
   - 服务器错误
   - 超时处理
   - 用户友好的错误消息

4. 请求配置：
   - 超时时间: 30s
   - 重试机制: 3 次
   - 请求头: Content-Type, Authorization (如需)

代码规范：
- 使用 axios
- Promise 链式调用
- 错误处理完善
- 日志记录
```
