# 阶段 1: 项目初始化

## 任务描述
初始化项目结构、配置开发环境、建立 Git 工作流。

## 交付物
- [ ] 项目目录结构完整
- [ ] 前后端 package.json 配置
- [ ] .env 环境变量模板
- [ ] .gitignore 配置
- [ ] Git 分支创建 (develop)
- [ ] README.md 完善

## 后端初始化提示词

```
你是一个资深 Node.js 全栈工程师。

任务：初始化 Fanshi-vidio-clone 项目的后端部分。

要求：
1. 在 backend/ 目录创建 Express.js 项目
2. 安装依赖：express, dotenv, cors, morgan, mysql2, sequelize, joi, winston
3. 创建以下目录结构：
   - config/ (数据库、环境配置)
   - routes/ (API 路由)
   - controllers/ (业务逻辑)
   - services/ (外部服务集成)
   - models/ (数据模型)
   - middleware/ (中间件)
   - utils/ (工具函数)
   - uploads/ (文件存储)

4. 编写 server.js 入口文件，配置：
   - Express 基础设置
   - CORS 中间件
   - 日志中间件 (morgan)
   - 错误处理中间件
   - 静态文件服务

5. 创建 .env.example 模板，包含：
   - NODE_ENV
   - PORT
   - DB_HOST, DB_USER, DB_PASSWORD, DB_NAME
   - GEMINI_API_KEY
   - SEED_DANCE_API_KEY
   - JWT_SECRET
   - FILE_UPLOAD_LIMIT

6. 编写 config/env.js 加载环境变量
7. 编写 config/database.js 配置 MySQL 连接
8. 编写 config/constants.js 定义常量

代码规范：
- 使用 ES6+ 语法
- 错误处理完善
- 注释清晰
- 遵循 MVC 架构
```

## 前端初始化提示词

```
你是一个资深 React 全栈工程师。

任务：初始化 Fanshi-vidio-clone 项目的前端部分。

要求：
1. 使用 Vite 创建 React 项目
2. 安装依赖：react, react-dom, axios, zustand, tailwindcss, @tailwindcss/forms
3. 创建以下目录结构：
   - components/ (可复用组件)
   - pages/ (页面)
   - services/ (API 调用)
   - hooks/ (自定义 Hooks)
   - store/ (状态管理)
   - styles/ (全局样式)
   - utils/ (工具函数)

4. 配置 Tailwind CSS
5. 创建 .env.example 模板，包含：
   - VITE_API_BASE_URL
   - VITE_UPLOAD_LIMIT

6. 编写 src/services/api.js 创建 axios 实例
7. 编写 src/App.jsx 基础布局
8. 编写 src/index.css 全局样式

代码规范：
- 使用函数组件 + Hooks
- 使用 Zustand 管理状态
- Tailwind CSS 样式
- PropTypes 类型检查
```

## Git 工作流提示词

```
你是一个 Git 工作流专家。

任务：为 Fanshi-vidio-clone 项目建立 Git 工作流。

要求：
1. 从 main 分支创建 develop 分支
2. 创建 .gitignore 文件，忽略：
   - node_modules/
   - .env (保留 .env.example)
   - dist/
   - build/
   - uploads/
   - *.log
   - .DS_Store

3. 编写 CONTRIBUTING.md 说明：
   - 分支命名规范 (feature/*, bugfix/*, hotfix/*)
   - Commit 消息规范 (feat:, fix:, docs:, style:, refactor:, test:, chore:)
   - PR 流程
   - 代码审查要求

4. 创建 .github/workflows/ CI/CD 配置 (可选)
```
