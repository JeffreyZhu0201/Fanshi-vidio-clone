## Docker 容器化提示词

```
你是一个资深 DevOps 工程师。

任务：为 Fanshi-vidio-clone 项目配置 Docker 容器化。

要求：

1. 创建后端 Dockerfile (backend/Dockerfile):
   - 基础镜像: node:18-alpine
   - 安装依赖
   - 复制代码
   - 暴露端口 5000
   - 启动命令

2. 创建前端 Dockerfile (frontend/Dockerfile):
   - 构建阶段: node:18-alpine (构建 React 应用)
   - 运行阶段: nginx:alpine (提供静态文件)
   - 配置 Nginx
   - 暴露端口 3000

3. 创建 docker-compose.yml:
   - 后端服务 (backend)
   - 前端服务 (frontend)
   - MySQL 服务 (mysql)
   - Redis 服务 (redis, 可选)
   - 网络配置
   - 卷配置

4. 优化 Docker 镜像：
   - 使用 Alpine 基础镜像
   - 多阶段构建
   - 最小化镜像大小
   - 缓存优化

5. 安全配置：
   - 非 root 用户运行
   - 只读文件系统
   - 资源限制

代码规范：
- 清晰的 Dockerfile 注释
- 最佳实践遵循
- 镜像大小优化
```

## 备份恢复方案提示词

```
你是一个资深数据保护专家。

任务：为 Fanshi-vidio-clone 项目设计备份恢复方案。

要求：

1. 备份策略：
   - 备份频率: 每天 1 次全量 + 每小时 1 次增量
   - 备份保留: 30 天本地 + 90 天云存储
   - 备份验证: 每周恢复测试

2. 备份内容：
   - 数据库备份 (MySQL)
   - 文件备份 (上传文件、生成文件)
   - 配置备份 (.env、nginx.conf)
   - 代码备份 (Git 仓库)

3. 备份存储：
   - 本地存储: /backup/
   - 云存储: AWS S3 或阿里云 OSS
   - 异地备份: 不同地域

4. 恢复流程：
   - 评估损失
   - 选择恢复点
   - 执行恢复
   - 验证数据
   - 恢复服务

5. 恢复时间目标 (RTO):
   - 数据库: < 1 小时
   - 文件: < 30 分钟
   - 服务: < 2 小时

代码规范：
- 自动化备份脚本
- 备份验证脚本
- 恢复测试脚本
- 详细的文档
```

## 部署命令示例

```bash
# 构建镜像
docker-compose build

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 备份数据库
./scripts/backup.sh

# 恢复数据库
./scripts/restore.sh

# 部署新版本
./scripts/deploy.sh

# 回滚版本
./scripts/rollback.sh

# 健康检查
./scripts/health-check.sh
```
