## 端到端测试现状
- Cypress 脚本已完成，覆盖上传、分析、切分、优化提示词、生成、拼接、下载主流程。
- 当前这台 Ubuntu 22.04 开发机在执行 `cd frontend && npm run test:e2e` 时缺少系统依赖 `Xvfb`。
- 阻塞现象已确认：Cypress 可启动验证流程，但最终报错 `spawn Xvfb ENOENT`。
- 结论：E2E 用例“已实现但当前机器未跑通”，不是脚本缺失，而是本机图形依赖未安装。

## 性能优化落地项
- 后端：
  - 增加 `compression`，压缩超过 `1KB` 的响应。
  - 增加 `express-rate-limit`，对 `/api` 增加基础限流。
  - 增加 Prometheus 指标采集，覆盖请求总数、耗时、活跃请求数、前端监控事件数。
- 前端：
  - `App.jsx` 改为页面级懒加载，减少首屏同步加载体积。
  - 增加 `performanceMonitor.js`，采集 `FCP`、`LCP`、`CLS` 与运行时错误。
  - WebSocket 服务增加关闭/降级逻辑，测试与异常场景自动回退到轮询。
  - Vite 默认开发主机改为 `127.0.0.1`，降低开发期暴露面。

- 默认目标：
  - 基准地址：`http://127.0.0.1:5000`
