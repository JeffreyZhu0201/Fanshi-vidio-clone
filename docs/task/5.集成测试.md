## 集成测试提示词

```
你是一个资深 QA 测试工程师。

任务：为 Fanshi-vidio-clone 项目编写集成测试。

要求：

1. 使用 Jest + Supertest (后端) 和 Cypress (前端)

2. 后端集成测试 (backend/__tests__/):
   - 测试视频上传流程
   - 测试 Gemini 分析流程
   - 测试 FFmpeg 分割流程
   - 测试视频拼接流程
   - 测试错误处理

3. 前端集成测试 (frontend/cypress/):
   - 测试上传视频
   - 测试查看分析结果
   - 测试编辑提示词
   - 测试生成片段
   - 测试拼接视频
   - 测试下载视频

4. 测试场景：
   - 正常流程 (Happy Path)
   - 边界情况 (Edge Cases)
   - 错误处理 (Error Cases)
   - 并发操作 (Concurrency)

5. 测试数据：
   - 创建测试视频文件
   - 创建测试数据库
   - Mock 外部 API

6. 测试报告：
   - 覆盖率报告
   - 性能报告
   - 缺陷报告

代码规范：
- 清晰的测试描述
- 完善的 setup/teardown
- 独立的测试用例
- 可重复执行
```

## 性能优化提示词

```
你是一个资深性能优化专家。

任务：为 Fanshi-vidio-clone 项目进行性能优化。

要求：

1. 后端性能优化：
   - 数据库查询优化 (添加索引、使用 JOIN)
   - 缓存策略 (Redis 缓存分析结果)
   - 异步任务队列 (Bull 或 RabbitMQ)
   - 连接池配置
   - 日志级别优化

2. 前端性能优化：
   - 代码分割 (Code Splitting)
   - 懒加载组件
   - 图片优化 (WebP、压缩)
   - 虚拟滚动 (大量片段列表)
   - 缓存策略 (Service Worker)

3. 网络优化：
   - 启用 Gzip 压缩
   - CDN 加速
   - 请求合并
   - 减少 HTTP 请求

4. 数据库优化：
   - 查询优化
   - 索引优化
   - 分页查询
   - 连接池

5. 性能基准测试：
   - 页面加载时间 < 3s
   - API 响应时间 < 500ms
   - 视频上传速度 > 10MB/s
   - 内存占用 < 500MB

代码规范：
- 使用性能分析工具
- 记录优化前后数据
- 文档化优化方案
```

## 安全加固提示词

```
你是一个资深安全工程师。

任务：为 Fanshi-vidio-clone 项目进行安全加固。

要求：

1. 后端安全：
   - 输入验证 (防 SQL 注入、XSS)
   - 认证授权 (JWT、权限检查)
   - 文件上传安全 (类型检查、病毒扫描)
   - API 速率限制
   - CORS 配置
   - HTTPS 配置
   - 敏感信息加密 (密码、API Key)
   - 日志审计

2. 前端安全：
   - XSS 防护 (React 自动转义)
   - CSRF 防护 (Token 验证)
   - 敏感信息不存储本地
   - 安全的 Cookie 配置
   - 内容安全策略 (CSP)

3. 数据库安全：
   - 参数化查询
   - 最小权限原则
   - 数据加密
   - 备份策略

4. 基础设施安全：
   - 防火墙配置
   - 端口限制
   - 日志监控
   - 入侵检测

5. 安全审计：
   - 代码审查
   - 依赖扫描 (npm audit)
   - 漏洞扫描
   - 渗透测试

代码规范：
- 遵循 OWASP Top 10
- 安全编码实践
- 完善的错误处理
- 详细的日志记录
```
